# 🎮 Clan Chat

**Discord-подобный чат с голосовыми каналами** — деплоится на **Render.com бесплатно** за 3 минуты.

## ✨ Фичи

| Категория | Что есть |
|---|---|
| 💬 **Текст** | Каналы, треды (ответы), реакции, код-блоки, маркдаун, редактирование/удаление своих |
| 🎤 **Голос** | WebRTC mesh (P2P) — до 8-10 человек без медиа-сервера |
| 🔧 **Настройки звука** | Выбор микрофона/наушников, **RNNoise шумоподавление**, эхоподавление, автогейн |
| ⌨️ **Push-to-Talk** | Любая клавиша (по умолчанию X) |
| 👤 **Авторизация** | Ник + пароль, JWT в localStorage, никакого email/телефона |
| 🌙 **Тема** | Discord Dark (авто по системной теме) |
| 📱 **Мобильно** | Работает в браузере на iOS/Android (PWA-ready) |
| ☁️ **Деплой** | Render.com Free Tier — HTTPS, автодеплой, 1 ГБ диск для БД |

## 🚀 Быстрый деплой (3 минуты)

### 1. Форкни репозиторий
Нажми **Fork** в правом верхнем углу → выбери свой аккаунт.

### 2. Подключи к Render
1. Зайди на [dashboard.render.com](https://dashboard.render.com) → **New +** → **Blueprint**
2. Выбери свой форк → **Apply**
3. Render создаст:
   - **Web Service** (Docker)
   - **Disk** 1 ГБ для SQLite
   - **JWT_SECRET** — сгенерирует автоматически
4. Жди 2-3 минуты билда → появится ссылка `https://matiz-chat-xxxx.onrender.com`

### 3. Готово!
Кидай ссылку клану → все заходят, регистрируются ник+пароль, общаются в войсе.

## 🛠 Локальная разработка

```bash
# Клонируй свой форк
git clone https://github.com/ТВОЙ_НИК/matiz-chat.git
cd matiz-chat

# Ставим зависимости
npm install

# Запуск (порт 3000)
npm start

# Открываешь http://localhost:3000
```

> **Для голоса нужен HTTPS** — локально используй `mkcert` или `ngrok`:
> ```bash
> npx ngrok http 3000
> # Открой https://xxxx.ngrok-free.app
> ```

## 📱 Для клановцев (инструкция кидай в общий чат)

> **Matiz Squad Chat — наш новый Discord**
> 
> 1. Переходи по ссылке: `https://matiz-chat-xxxx.onrender.com`
> 2. **Регистрация** → придумываешь ник + пароль (никакой почты/телефона)
> 3. Заходишь в каналы слева:
>    - `#general` — общий чат
>    - `#memes` — мемы
>    - `#demos` — демки/клипы
> 4. **Голос** → заходи в `🔊 Главный войс` или `🎮 Чилл войс` → жми **«Войти»**
> 5. В настройках голоса выбери микрофон/наушники, включи **Шумоподавление**
> 6. **Push-to-Talk** (клавиша X) — включи в настройках, если нужно
> 
> **Мобильные:** работает в Chrome/Safari — добавь на главный экран (Share → Add to Home Screen)

## 🏗 Архитектура

```
┌─────────────────────────────────────────────────────────────┐
│  Render Free Tier                                           │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Node.js (Express + Socket.io)                      │   │
│  │  ├─ REST API: /api/auth, /api/channels, /api/...    │   │
│  │  └─ WebSocket: Socket.io (chat, typing, voice)      │   │
│  │                                                       │   │
│  │  Better-SQLite3 (файл на Disk 1 ГБ)                 │   │
│  │  ├─ users, channels, messages                       │   │
│  │  └─ channel_members (voice tracking)                │   │
│  └─────────────────────────────────────────────────────┘   │
│                          │                                  │
│                    HTTPS/WSS                                 │
│                          ▼                                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Браузеры клановцев (P2P WebRTC Mesh)               │   │
│  │  ├─ Текст/сигналинг → Socket.io                     │   │
│  │  └─ Аудио/видео → RTCPeerConnection (mesh)          │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**Ограничения Free Tier:**
- WebRTC **mesh** — работает до ~8-10 человек в голосовом канале
- Для 20+ нужен SFU (Jitsi/LiveKit) — не влезет в 512 МБ RAM
- База на диске 1 ГБ — хватает на годы чата
- Сервер «засыпает» после 15 мин неактивности (холодный старт ~30 сек)

## 🔧 Кастомизация

### Добавить каналы
```javascript
// В db.js функция init() — добавь в массив:
insertChannel.run('custom', 'custom', 'text', 'Описание', 99, now);
```

### Сменить тему
В `public/style.css` поменяй CSS переменные в `:root`.

### Добавить бота
Подключись к Socket.io из отдельного скрипта:
```js
const io = require('socket.io-client');
const socket = io('https://your-app.onrender.com', { auth: { token: 'BOT_TOKEN' } });
```

## 🐛 Известные проблемы

| Проблема | Решение |
|---|---|
| Голос не работает на iOS Safari | iOS требует жест пользователя — первый клик по кнопке «Войти» должен быть от пользователя (у нас так) |
| Эхо в наушниках | Включи **Эхоподавление** в настройках голоса, используй закрытые наушники |
| Лаги при 10+ в войсе | Mesh нагружает CPU — для больших групп нужен SFU (не в бесплатном тиере) |
| Сообщения не приходят | Проверь WS в DevTools → Network → WS — должен быть `101 Switching Protocols` |
